# 다중 세션 터미널 배정과 경로 결정 문제

WCNC 2027 투고 연구(세션 하나)의 위성망 모델을 그대로 쓰고, 여러 세션이 위성의
재구성 터미널과 링크 용량을 나눠 쓰는 경우로 넓힌 문제다. 코드는 `multisession/`이다.

## 1. WCNC 모델에서 그대로 가져온 것

- 3차원 원궤도 Walker-Delta 1,584기(궤도면 24개 × 66기, 위상 11, 고도 550 km, 경사 53°)
- 위성 간 링크 최대 거리 1,500 km, 지상-위성 링크 최대 거리 1,000 km, 접촉 구간은 미리 계산한 캐시
- 위성마다 같은 궤도면 앞뒤를 잇는 고정 터미널 2개와 다른 궤도면을 잇는 재구성 터미널 1개
- 재구성은 기존 링크를 먼저 끊고 새 상대를 잡는다. 새 링크는 20초 뒤에 켜진다.
  한 경로에 새 링크가 여러 개면 병렬로 잡으므로 경로당 20초 한 번이다.
- 세션 도착 전의 초기 동적 링크 배치(세션과 무관한 짝짓기)
- 지상국 4곳과 경로 쌍 3개(뉴욕에서 런던, 이스탄불, 하노이로)

## 2. 바꾸거나 더한 것과 이유

| 항목 | 내용 | 이유 |
|---|---|---|
| 링크 용량 κ | 위성 간 링크 하나가 동시에 싣는 세션 수(양방향 합) | 용량이 없으면 세션들이 같은 경로를 함께 써서 경쟁이 생기지 않는다 |
| 지상국 안테나 A | 남은 접촉 시간이 긴 순서로 보이는 위성 A개를 동시에 잡는다 | 세 경로 쌍이 모두 뉴욕에서 출발하므로 A=1이면 위성 하나의 링크 3개가 모든 세션을 막는다 |
| 경로 고정 | 결정한 경로를 세션이 끝날 때까지 쓴다(회선 예약) | 세션 도중 함께 다시 정하는 문제는 시간 확장 모델이 필요해 다음 단계로 둔다 |
| 유지 시간 X | 20, 60, 180초 | WCNC 실험 규약상 300, 600초는 지상 접속 전환이 꼭 생겨 경로를 고정할 수 없다 |
| 일괄 도착 | 시각 t₀에 세션 K개가 함께 도착한다 | 한 결정 시점에서의 경쟁을 본다 |
| 목표 | 받아들인 세션 수, 새 링크 수, 홉 수 | WCNC의 완주, 새 링크 수, 경로 길이 지표와 맞춘다 |

κ와 A는 실제 장비 수치를 주장하지 않는다. WCNC가 유지 시간 X를 통제 변수로 다룬 것처럼
값을 바꿔 가며 실험한다(κ = 1, 2, 4, A = 1, 2, 4). A=1, κ≥1, K=1이면 경로를 바꾸지 않는
WCNC 세션 문제와 같다.

## 3. 정식화

시각 t₀의 상태

- 위성 집합 V, 고정 링크 P (남은 접촉 시간 r_e = ∞)
- 동적 링크 후보 D: t₀에 접촉 중인 다른 궤도면 위성 쌍과 남은 접촉 시간 r_e
- 초기 동적 링크 M₀ ⊆ D (위성마다 최대 1개)
- 지상국 o의 안테나 위성 S_o (A개)와 각 지상 링크의 남은 접촉 시간 g_{o,s}
- 세션 k = (o_k, d_k, X_k), k ∈ K

결정

- 최종 동적 링크 M ⊆ D, 새 링크 N = M \ M₀
- 받아들일 세션 K' ⊆ K와 각 k ∈ K'의 단순 경로 p_k (S_{o_k}의 위성에서 S_{d_k}의 위성까지, P ∪ M 위)

제약

- (C1) 터미널: 모든 위성 v에 대해 M에서 v에 닿는 링크는 최대 1개
- (C2) 설정 지연: σ_k = 20초 (p_k가 N의 링크를 하나라도 쓰면), 아니면 0
- (C3) 수명: p_k의 모든 링크 e에 대해 r_e ≥ σ_k + X_k, 양 끝 지상 링크도 g ≥ σ_k + X_k
- (C4) 용량: P ∪ M의 모든 링크 e에 대해 e를 쓰는 세션 수 ≤ κ

(C1) 때문에 한 경로가 한 위성에서 동적 링크 두 개를 쓸 수 없다(WCNC 경로 탐색과 같은 규칙).
(C2)와 (C3) 때문에, 이번 결정에서 새로 켠 링크는 20초를 기다리는 세션만 쓸 수 있다.

목표 (사전식 순서)

1. 받아들인 세션 수 |K'| 최대
2. 새 링크 수 |N| 최소 (재구성 작업, 링크 설정 20초)
3. 위성 간 홉 수의 합 최소

## 4. 복잡도

κ=1이고 새 링크를 금지하면, 세션을 최대한 많이 받아들이는 문제는 간선이 겹치지 않는 경로를
최대한 많이 찾는 문제가 된다. 정수 다중 상품 흐름은 상품이 2개이고 용량이 1이어도
NP-완전이다(Even, Itai, Shamir, SIAM J. Comput. 1976). 따라서 이 문제의 일반형은 NP-hard다.
이 말은 임의의 그래프를 입력으로 받는 일반형에 대한 것이고, 특정 위성망 인스턴스가 어렵다는
뜻은 아니다. 그래서 정확해 모델의 풀이 시간과 기준 방법의 차이를 실험으로 잰다.

## 5. 정확해 모델 (CP-SAT)

출발지, 도착지, X가 같은 세션은 서로 바꿔도 같다. 그래서 세션마다 경로 변수를 두지 않고,
도착지 d와 지연 여부(즉시 σ=0, 지연 σ=20)마다 정수 흐름 하나를 둔다.

- 즉시 흐름은 고정 링크와 유지된 초기 동적 링크(M ∩ M₀)만, r_e ≥ X인 것만 쓴다.
- 지연 흐름은 M의 모든 링크를, r_e ≥ 20 + X인 것만 쓴다.
- 링크 용량은 모든 흐름의 양방향 합 ≤ κ, 동적 링크는 켜진 경우(y_e = 1)에만 쓴다.
- 위성마다 켜진 동적 링크는 최대 1개다.

원래 해는 새 링크를 쓰는 세션을 지연 흐름으로, 나머지를 즉시 흐름으로 옮기면 같은 목표값의
해가 된다. 거꾸로 흐름 해는 단위 경로로 분해하면 원래 문제의 해가 된다. 지연 흐름의 경로가
새 링크를 쓰지 않아도 r_e ≥ 20 + X ≥ X이므로 제약을 지킨다. 홉 수를 최소화하므로 최적해에는
순환이 없다. 따라서 두 모델은 최적값이 같다. 풀이 결과는 경로로 분해한 뒤 독립 검증기
(`multisession/model.py`의 `verify`)로 다시 확인한다.

## 6. 기준 방법과 상한

- 고정 배치: 초기 동적 링크를 그대로 두고, 세션을 순서대로 용량과 수명을 지키는 최소 홉 경로로
  받아들인다. 경로가 없으면 거절한다.
- 탐욕 재구성: 같은 방식으로 먼저 찾고, 없으면 쓰이지 않는 재구성 터미널을 새 상대로 돌려
  (새 링크 수, 홉 수)가 가장 작은 경로를 찾는다.
- 차단 상한: 위성마다 링크가 최대 3개이고 링크마다 세션 κ개이므로, 지상국에서 쓸 수 있는
  안테나 위성이 s개면 그 지상국을 지나는 세션은 최대 3κs개다. 정확해가 없을 때의 상한으로 쓴다.

## 7. 실험 설계

- 결정 시각: WCNC 고정 테스트 요청 중 경로 쌍 short, X=20초의 시각 240개(한 궤도 주기)에서
  고르게 40개를 고른다. 짝수 번째 20개는 검증용(방법 설계와 조정), 홀수 번째 20개는 테스트용이다.
  테스트용은 방법을 확정한 뒤 한 번만 돌린다.
- 요인: A ∈ {1, 2, 4}, κ ∈ {1, 2, 4}, 도착지당 세션 수 ∈ {2, 4, 8, 16}, X ∈ {20, 60, 180}초
- 세션 순서: 도착지를 번갈아 놓아 어느 도착지도 먼저 처리되지 않게 한다.

## 8. 지표

받아들인 세션 비율, 정확해 대비 차이, 새 링크 수, 평균 홉 수, 계산 시간.

## 9. 한계

- 세션 도중 경로를 바꾸지 않는다. WCNC는 도중 변경을 허용하므로 그 결과와 수치를 직접 비교하지 않는다.
- 지상 구간 용량과 안테나 전환 시간은 다루지 않는다.
- κ와 A는 통제 변수다. 실제 링크 대역폭이나 지상국 안테나 수를 주장하지 않는다.
